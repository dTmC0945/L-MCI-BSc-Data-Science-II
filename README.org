* Lecture Information






** Lecture Overview

Welcome to B.Sc Data Science II

The goal of this lecture is to give you a much deeper understanding of how
machine learning algorithms work. To this end we will continue where we have
left off in B.Sc Data Science I and start with Artifical Neural Networks.

From there-on we shall have a look at current challenges which are tacked such
as Natural Language Processing (NLP), Generative AI, and Reinforcement Learning.
